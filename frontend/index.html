This project is a fully automated deployment pipeline that provisions a multi-environment serverless web application (Serverless Resume with a Visitor Counter) hosted on AWS serverless architecture using S3, Lambda, DynamoDB, and Terraform.

It is simple to code but proves that I can connect critical cloud architecture components.
